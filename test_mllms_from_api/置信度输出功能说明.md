# 相对测试置信度输出功能 - 修改说明

## 概述

已成功修改代码，让相对测试输出0-1之间的置信度值（而不是简单的0或1），用于计算AUC分数。

## 主要修改内容

### 1. 提示词修改 (`get_analysis_prompt` 方法)
- **原始格式**: 要求输出"Comparison result: 1"或"Comparison result: 0"
- **新格式**: 要求输出"Comparison result: X"，其中X是0.0-1.0之间的小数

#### 置信度含义：
- **1.0**: 非常确信VIDEO 1的物理属性值更高
- **0.8**: 比较确信VIDEO 1的物理属性值更高  
- **0.6**: 有些确信VIDEO 1的物理属性值更高
- **0.5**: 相等或不确定（没有明显差异）
- **0.4**: 有些确信VIDEO 2的物理属性值更高
- **0.2**: 比较确信VIDEO 2的物理属性值更高
- **0.0**: 非常确信VIDEO 2的物理属性值更高

### 2. 结果提取修改 (`extract_comparison_result` 方法)
- **返回类型**: 从`Optional[int]` 改为 `Optional[float]`
- **提取逻辑**: 
  - 主要模式：正则匹配"Comparison result: X.X"格式
  - 备用模式1：从文本中提取0-1范围内的小数
  - 备用模式2：从文本描述推断置信度（如"VIDEO 1 has higher"→0.8）
  - 备用模式3：从不确定性关键词推断（如"equal"→0.5）

### 3. ICL示例修改
- **ICL输出格式**: 从"Comparison result: 1"改为"Comparison result: 0.9"等高置信度值
- **置信度设置**:
  - VIDEO 1 > VIDEO 2 → 置信度 0.9
  - VIDEO 2 > VIDEO 1 → 置信度 0.1  
  - 相等情况 → 置信度 0.5

## AUC计算说明

现在您可以使用置信度分数计算AUC：

```python
from sklearn.metrics import roc_auc_score
import numpy as np

# 示例数据
predictions = [0.9, 0.2, 0.7, 0.3, 0.8]  # 模型置信度分数
ground_truth = [1, 0, 1, 0, 1]           # GT标签（1表示VIDEO 1确实更大）

# 计算AUC
auc_score = roc_auc_score(ground_truth, predictions)
print(f"AUC分数: {auc_score:.3f}")
```

## 注意事项

1. **向后兼容性**: GT标签仍然是0或1，只有预测值改为置信度分数
2. **文件格式**: 结果文件格式保持不变，只是predicted字段现在是浮点数
3. **错误处理**: 增强了对API错误和异常情况的处理

## 技术细节

- 正则表达式模式：`r"Comparison result:\s*([0-1](?:\.\d+)?)"`
- 备用提取使用多种启发式方法确保鲁棒性
- ICL示例使用高置信度值（0.9/0.1）而非中间值，提供更清晰的训练信号
